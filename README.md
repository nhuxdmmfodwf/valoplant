## Overview

ValoPlant is a dedicated Valorant statistics tracker that aggregates match history, agent win rates, weapon accuracy, map-specific performance, and rank progression charts. It provides both personal performance analysis and detailed opponent scouting before competitive matches.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **ValoPlant** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Match History** | Full match history with per-agent, per-map, and per-weapon breakdowns |
| **Rank Tracking** | Visual rank progression history over time with RR gain/loss graphs |
| **Agent Stats** | Win rate, ACS, and K/D analysis per agent across recent sessions |
| **Opponent Scout** | Look up current match opponents' ranked stats and agent trends |
